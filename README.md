## Identificação do tema do aplicativo

Aplicativo mobile informativo, orientado a objetos, sobre o filme **Gremlins (1984)**. O app apresenta enredo, dados técnicos, elenco, detalhes de produção, curiosidades e links oficiais ou institucionais relacionados à obra e aos artistas quando houver.
