# Gremlins Mobile

## Nomes dos alunos

Guilherme Nunes Dos Santos
Filipe Ichiro Rabelo Okuizumi

## Identificação do tema do aplicativo

Aplicativo mobile informativo sobre o filme **Gremlins (1984)**.

O aplicativo apresenta enredo, dados técnicos, elenco, detalhes, curiosidades e links oficiais ou institucionais relacionados ao filme e aos artistas quando houver.
